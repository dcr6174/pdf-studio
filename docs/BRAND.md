# PDF Studio

The refreshed identity uses a folded ribbon S mark with violet, coral and turquoise facets. A quiet white working canvas, violet controls, coral editing accents and teal conversion accents organize the interface. Existing saved drafts, local files and theme choices retain their original storage keys so the rename does not erase user data.

Logo asset: `public/brand/pdf-studio-mark.png`. Generated with the built-in image-generation tool, then copied unmodified into the project. Transparent raster artwork; a production vector master is not included.

Prompt: Create one polished original app logo mark for PDF Studio, a friendly professional open-source PDF workspace. No text or letters. A bold abstract folded ribbon / page-corner motif suggesting a flowing S, thick rounded angular geometry with generous clean negative space, violet and vivid coral main facets with a small turquoise facet. Modern flat vector-like logo, only three solid colors, extremely crisp edges, recognizable at 32 pixels, perfectly centered square composition, mark fills 85% of canvas. Transparent background. No tile or background circle, no shadows, no gradients, no mockup, no typography, no stacked-page Layers icon.

The generated artwork has subtle color variation. It is used as the app mark and favicon; functional tool icons remain Lucide icons. No competitor assets are used.
