# PDF Studio brand: Page Buddy (v5)

## The mark
A friendly page with a folded-corner "tuft", soft 3D shading and a simple face.
Use the default (smiling) face for the logo. The other faces are for the interface only.

## Files
- svg/pdf-studio-logo-v5.svg: primary mark (colour, soft shadow)
- svg/pdf-studio-lockup-v5.svg / -dark.svg: mark + "pdf studio" (text converted to shapes)
- svg/pdf-studio-stacked-v5.svg / -dark.svg: mark above the name (posters, splash screens)
- svg/pdf-studio-favicon-v5.svg: simplified for 16-32 px (no shadow, no blush, bigger eyes)
- svg/pdf-studio-mono-ink-v5.svg / mono-white: one colour (print, stamps, embossing)
- svg/pdf-studio-app-icon-v5.svg: lavender tile
- svg/buddy-success.svg, buddy-oops.svg, buddy-sleepy.svg: expressions for done / error / empty states
- png/: 512 logo, app icons 192/512, Android maskable 512, Apple touch 180, favicon 16/32/48 and .ico, lockup PNGs at 4x

## Colours
| Name | Hex | Use |
|---|---|---|
| Violet | #6A4DFF | Brand colour, page body |
| Deep violet | #4B2FE0 | Gradient end, shadows |
| Ink | #1B1640 | Face, wordmark, text |
| Lavender | #EDE9FF | App icon tile, soft backgrounds |
| Blush | #FF8FB8 | Cheeks only |
| Mint | #22C79E | Small accents (success, the "z" in sleepy) |

## Type
Wordmark: Outfit Bold, lowercase "pdf studio", converted to outlines. Outfit is free (SIL Open Font License).

## Rules
- Keep clear space around the mark equal to the height of one eye on every side.
- Minimum size: lockup 96 px wide; mark alone 20 px (use the favicon file below 32 px).
- Don't recolour the gradient, stretch it, add outlines, or change the face on the main logo.
- On busy photos use the lavender app tile or the one-colour white version.
